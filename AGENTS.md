# Работа с проектом

Перед изменениями прочитайте README и документы PROJECT, STATE, TASKS и HANDOFF в docs/. Сверяйте документацию с кодом и текущим развёртыванием. Обновляйте STATE и HANDOFF после значимых изменений. Используйте ветки и pull requests. Храните рабочую конфигурацию и дампы вне Git.
