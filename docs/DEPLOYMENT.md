# Развёртывание

Разверните публичные файлы в каталоге сайта, создайте отдельную базу, импортируйте проверенный дамп и настройте config.php. Перенесите ограничения доступа к внутренним файлам из конфигурации веб-сервера. Проверьте независимую работу копии, включая HTTPS, афишу, админку и безопасную тестовую заявку. Перед переключением синхронизируйте свежие записи базы. Сохраните действующие DNS-записи для почты и поддоменов и прежний адрес как точку отката.
