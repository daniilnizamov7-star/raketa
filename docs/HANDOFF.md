# Передача работы

Beget обслуживает сайт и принимает заявки. Пользователь подтвердил почту и Telegram. Подробности проверок и сохранённых баз находятся в STATE.md.

Предстоит финальная сверка данных и отключение компонентов Ракеты в Selectel с архивом для отката. Сервер общий с другими проектами, включая СИТИГО. Для этого этапа сетевой доступ в последнем запросе не предоставлен. GitHub CLI требует восстановления авторизации. Подготовленная ветка migration/beget содержит рабочий снимок файлов и документацию без конфигурации и базы.
