# Передача работы

Beget обслуживает сайт и принимает заявки. Пользователь подтвердил доставку почты от адреса парка и уведомлений Telegram. HTTPS основного домена и www, перенаправление HTTP на HTTPS и запрет доступа к config.php проверены. Подробности сохранённых баз находятся в STATE.md.

Рабочий снимок сайта и документация опубликованы в PR #1. Добавлены используемые при развёртывании правила .htaccess. Реквизиты и дампы исключены из Git.

Остаются финальная сверка данных, архивирование и отключение компонентов Ракеты в Selectel. Сервер общий с другими проектами, включая СИТИГО. Сетевой доступ для SSH в последнем запросе не предоставлен. Историческую базу Beget необходимо сохранить отдельно. Также предстоит проверить поддомен админки и SPF, DKIM, DMARC.
